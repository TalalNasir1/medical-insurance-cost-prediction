# Medical Insurance Cost Prediction

This free static deployment runs the exact fitted Linear Regression equation in the browser. The original `insurance_model.pkl`, feature order, metadata, notebook, Gradio application, and full documentation are available in the [GitHub repository](https://github.com/TalalNasir1/medical-insurance-cost-prediction).

The model was trained on the Medical Cost Personal Dataset using eight inputs: age, BMI, children, sex, smoking status, and three one-hot-encoded region columns. It achieved an R² score of **0.8069** on the held-out test set.
