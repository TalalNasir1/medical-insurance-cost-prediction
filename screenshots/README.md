# Screenshot checklist

Add the final evidence images here before submission. Suggested filenames:

1. `01-github-repository.png` — repository home and file list
2. `02-readme.png` — rendered README page
3. `03-deployed-application.png` — live Hugging Face Space interface
4. `04-prediction-test-case-1.png` — first completed prediction
5. `05-prediction-test-case-2.png` — second completed prediction
6. `06-project-structure.png` — complete repository structure

Use two meaningfully different prediction cases, such as a non-smoker and a
smoker, so the evidence demonstrates that the application accepts different
inputs and returns predictions.
